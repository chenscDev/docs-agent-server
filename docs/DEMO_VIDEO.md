# 演示短视频要点（Demo Video）

目标：1 条 **60～90 秒** 主视频（投递附件 / 作品集页），可选再剪一条 **25～30 秒** 短版。  
不要求专业器材：手机录屏 + 电脑录屏画中画即可。

## 拍摄准备

1. 按 [DEMO_SCRIPT.md](./DEMO_SCRIPT.md) Checklist 预热环境。  
2. 分辨率：手机竖屏 1080p，或横屏电脑窗口 + 手机画中画。  
3. 关闭通知；后端终端可放角落（可选，证明非纯 Mock）。  
4. 语料用 `eval/corpus/acme_handbook.md`，问题固定，避免临场卡壳。  
5. 口播可后期配音；现场声嘈杂就后期念 30 秒 / 90 秒稿。

## 推荐镜头表（90 秒版）

| 秒 | 画面 | 旁白要点 |
|----|------|----------|
| 0–8 | 标题卡：文档问答 Agent · RN + FastAPI + RAG | 一句话场景 |
| 8–20 | 知识库：文档 `ready`（可加速上传过程） | 状态机，未 ready 不搜 |
| 20–45 | 聊天：提问「试用期…」→ 工具卡 → 流式字 → `[1]` | Agent + SSE 分层事件 |
| 45–60 | 点击引用 → Citation 全文 | chunk 二次查询、防幻觉链接 |
| 60–75 | 提问「产假…」→ 拒答 | 证据不足不编造 |
| 75–90 | 定格架构简图或气泡 `req=` + 字幕技术栈 | 可观测 / 薄客户端 |

**短版 30 秒：** 只保留「提问出字 + 点引用 + 技术栈字幕」，口播用电梯稿。

## 剪辑注意

- 上传 / Embedding 等待：**5× 加速**或跳切到 ready。  
- 工具卡出现至少停 **1 秒**，观众才看得出「先检索再生成」。  
- 字幕关键词：`Tool Calling` `SSE` `FAISS` `Citations` `RN 分包`。  
- 片尾加仓库说明（私有仓可写「可提供演示 / 代码走查」），**不要露出 `.env` / API Key**。  
- 若录了终端：确认日志无 Key、无完整身份证等敏感内容。

## 导出与命名

- 文件名示例：`docs-agent-demo-90s.mp4` / `docs-agent-demo-30s.mp4`  
- 封面：聊天页带引用的一帧 + 标题「文档问答 Agent」  
- 投递：网盘链接或作品集页；简历里写「演示视频见链接」，正文仍放文字项目描述

## 你需要亲自完成的部分

文档无法代替成片。建议今天或明天：

1. 按镜头表录一镜到底（可多条 take）  
2. 用剪映 / CapCut 按上表剪 90 秒  
3. 自己看一遍：陌生人能否在 20 秒内明白「这是带检索的 Agent」
