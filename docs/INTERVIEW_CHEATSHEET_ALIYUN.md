# 面经速查 · 阿里云 AI 应用研发（二面）

用法：关掉代码，按表从左到右口述——**先说项目事实，再说通用方案，最后诚实边界**。  
配套：`ARCHITECTURE.md` / `INTERVIEW_QA.md` / 本仓库评测 `eval/`。

> 来源：阿里云 AI 应用研发夏令营二面回忆（约 55～60min，无手撕）+ 通用 Agent 题补充。

---

## 三栏怎么用

| 栏 | 含义 | 面试口径 |
|----|------|----------|
| **项目事实** | docs-agent 里真实做过的 | 优先说，可追问到代码/日志 |
| **通用方案** | 业界常见做法（30～60 秒） | 证明你见过生产形态 |
| **边界 / 未做** | 明确没做 + 为何 + 演进 | 比硬蹭加分 |

## 2. 第一个项目向 · RAG / 解析 / 检索

| 题 | 项目事实 | 通用方案 | 边界 / 未做 |
|----|----------|----------|-------------|
| 工业 PDF：正文与表切开后跨元素关联丢失？ | 结构化切分带 `heading`；docx 抽段落+表文本；**无显式跨 chunk 边** | 同页 `page_id`/父块-子块；表头复制进每个表行块；检索后同页扩召回 | 未做跨页表合并、未上 MinerU；演进：metadata + 兄弟块扩窗 |
| Embedding 对公差等数字不敏感？ | 云 Rerank（gte-rerank-v2）+ 失败本地启发式；引用对齐 chunk | 混合检索（BM25/关键词）+ 数字单位规范化；规则补召 | 未专项做数字索引；可答「数字题靠 rerank + 字面」 |
| Top-K 有冲突文档，Prompt 怎么导？ | Prompt：只依据工具结果；无命中拒答；citations 仅合法 `[n]` | 要求「冲突则并列引用+出处，禁止私自调和」；按生效日期排序 | 单手册语料冲突少；无版本仲裁引擎 |
| MinerU 抽表/公式/图后怎么进向量库？ | PyMuPDF 文本层 + 扫描件 OCR（qwen-vl-ocr）；正文在 SQLite，向量在 FAISS | 多模态分库或统一元数据；图存对象存储+caption embedding | **没用 MinerU / Milvus**；图未单独建索引 |
| 跨页切块时图会不会丢？ | OCR 按页；切分按标题/段落窗口 | 图锚点挂最近标题；跨页图合并或 caption 进 chunk | 无独立「保图」管线 |
| Cross-encoder Rerank 延迟？大批量文档？ | FAISS 先拉 `RERANK_CANDIDATE_K` 再云 rerank；`usage.rerankUsed`；增量 FAISS | 候选截断；批推理；异步/缓存热 query | 无本地 CE 压测数字；勿编造 ms |
| 垂域 Embedding 语义偏移还有啥办法？ | 改写 query、指代改写、Rerank、结构化切分 | 垂域微调/LoRA、同义词表、HyDE（慎用）、人工标注 hard negative | 未做垂域微调；HyDE 未落地 |
| overlap 作用？chunk size vs 完整性？ | 标题→段落→窗口；过大成本↑噪声↑，过小切断条款 | overlap 保跨边界句；按结构优先再定长 | 无自动调参，靠评测回归 |

## 3. 第二个项目向 · Agent / 安全 / 编排

| 题 | 项目事实 | 通用方案 | 边界 / 未做 |
|----|----------|----------|-------------|
| 用户故意回避/撒谎，Agent 能否感知？ | 制度问答：**证据优先**，不以用户口述覆盖文档 | 对话策略：一致性检查、关键题回问、风险标记 | 非陪伴/风控 Agent；无行为画像模型 |
| MCP 工具返回超大 JSON 怎么截还不丢诊断信息？ | citations **短 snippet**；点引用再 `GET /chunks/{id}` 拉全文 | 摘要+指针（artifact id）；按 query 二次拉取字段 | 未接 MCP；同一思想已用在引用 |
| 模型过度共情导致情感依赖，Prompt 怎么控边界？ | System 定位文档问答；拒答写诗/域外题 | 「不扮演情感陪伴；偏题拉回业务」；敏感场景转人工 | 无情绪检测模型 |
| LangGraph 节点 I/O 契约？中间失败怎么回滚？ | **手写 Tool Loop**，非 LangGraph；失败走 `error` SSE + 消息 status | Typed state；失败节点补偿/重试；checkpoint | 无图状态回滚；单轮失败不脏写 ready 索引 |
| Guardrail：词典还是分类模型？敏感词后路径？ | 薄 Bearer；域外拒答靠 Prompt | 规则层 + 模型分类；命中→拦截/改写/人工 | 无完整安全中台、无危机分级 |
| 危机场景几级？何时人工？ | — | L1 自动拒答 → L2 降级话术 → L3 转人工/工单 | 未产品化 HITL |
| API 调用 vs 本地部署？模型怎么选？ | 通义云 API（Chat/Embed/Rerank/OCR） | 延迟/成本/数据出境/可控性；核心链路可混部 | 无本地大模型部署 |

## 4. Agent 工程通用（阿里面经后半 + 补充题）

| 题 | 项目事实 | 通用方案 | 边界 / 未做 |
|----|----------|----------|-------------|
| 检索为空或超时，Prompt 怎么兜底？ | 空命中→改写再搜（≤2 次 search）；仍空拒答；超时/错误 `error` | System 写死「无证据不编造」；超时返回可重试 | 无多级降级检索源 |
| Token 越来越大，怎么控单次会话预算？ | 历史约 8 条/~3k 字；hit 截断；search 次数上限 | 摘要旧轮、工具结果只留 summary+id、上下文缓存 | 无精确 token 计数器 UI |
| 场景走 Workflow 还是 Agent？ | **解析=状态机 Workflow**；**问答=有界 Agent** | 确定性高→Workflow；探索多→Agent；可混合 | 不做完全自由 Agent |
| ReAct 动作空间太大乱跳，怎么约束顺序？ | 小工具集；`search_docs` 上限；提示先检索再答 | 状态机锁序；允许列表；plan-then-act | 无支付级锁序 |
| 怎么保证稳定输出 JSON 调工具？格式错怎么兜？ | **原生 `tool_calls`**，不靠自由文本 JSON | JSON Schema / constrained decoding；校验失败重试或拒执行 | 未上 Outlines 等 |
| 多步推理中间步骤怎么流式给前端？ | SSE：`accepted`→`tool.*`→`delta`→`completed`；RN 渲染工具卡 | 事件模型先于全文；可取消 | 非 WebSocket |
| 多 Agent 拆分边界？何时不该拆？ | **单 Agent** 文档问答 | 按权限/模型/长任务并行拆；共享状态成本高则不拆 | 无 Multi-Agent |
| 多工具并发部分失败怎么汇总？ | 多为串行；单 tool 结果回灌 | 每 tool `ok/error`；Prompt 禁止用失败结果作答 | 未做真并发 fan-out |
| 上下文压缩有哪些方法？ | 截断历史；snippet；Citation 二次拉全文 | 摘要、向量检索历史、分层记忆 | 无自动摘要流水线 |
| A2A 和 MCP 各解决什么？何时用？ | 进程内 Function Calling | MCP=Agent↔工具；A2A=Agent↔Agent | 未接入；演进可把 search 封 MCP |
| 停止生成怎么做？ | `POST /cancel` + Abort；**close LLM httpx**；落库 cancelled | 协作取消 + 尽量掐断连接 | 跨进程 cancel 未做 |
| 提示词注入怎么防？ | 角色分离；工具结果当数据；Key 仅服务端 | 输入隔离、工具白名单、高危确认 | 无专门注入检测模型 |

## 6. 阿里云向 · 60 分钟口述优先级

1. **必深讲（用项目钉死）：** RAG 状态机、Tool Loop 上限、SSE、引用二次查询、空检索改写、Rerank、评测、cancel。  
2. **必会嘴炮：** 跨元素关联、数字敏感、冲突 Prompt、MCP 大 JSON≈你的 snippet 模式、Workflow vs Agent。  
3. **诚实对比：** 我们是 FAISS+SQLite+手写 Loop，不是 MinerU+Milvus+LangGraph——并说演进路径。
