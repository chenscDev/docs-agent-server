# 短视频创作 · 知识库约束样例

对应创作页「选择场景」快捷模板，上传到问答知识库后，在生成短视频时勾选即可约束口播与合规口径。

| 文件 | 对应场景 |
|------|----------|
| `01-产品种草口播规范.pdf` | 产品种草 / 电商种草玩法 |
| `02-招聘宣传口播规范.pdf` | 招聘宣传 / 招聘玩法 |
| `03-知识科普口播规范.pdf` | 知识科普 |
| `04-品牌开场片规范.pdf` | 品牌开场 |
| `05-活动促销口播规范.pdf` | 活动促销 / 电商促销玩法 |
| `06-本地生活口播规范.txt` | 本地生活 / 探店团购玩法 |

## 用法

1. 问答 Tab → 知识库 → 新建或选用一个库（如「短视频话术约束」）
2. 上传上表 PDF（可多选）
3. 等待解析为 ready
4. 首页创作：选对应场景描述，并在「知识库约束」中勾选该库 → 开始生成

同目录 `.txt` 为纯文本备份，服务端也可解析。
